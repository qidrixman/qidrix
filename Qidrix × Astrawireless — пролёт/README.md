# ASTRADRIVE для АГМК — пролёт над сценой

Интерактивная 3D-презентация Astrawireless × Qidrix: сеть ASTRADRIVE, техника, видео и телеметрия на карьерах Кальмакыр, Ёшлик-1 и Сарычеку. Запускается сама. Управление: стрелки ← → (шаги), пробел (пауза); шаги можно выбирать на полосе прогресса.

## Как выложить онлайн

Загружается содержимое папки **`site/`**. Это обычный статический сайт: внутри `index.html` и файлы рядом, сервер не нужен. Работает и в корне домена, и в любой подпапке.

- **Netlify Drop** (быстрее всего, без регистрации): откройте app.netlify.com/drop и перетащите папку `site`, получите ссылку.
- **GitHub Pages**: положите содержимое `site/` в репозиторий и включите Pages.
- **Любой хостинг или свой сервер**: скопируйте содержимое `site/` в папку сайта.

Открыть `index.html` двойным щелчком с диска не получится: браузеры не запускают такие модули с `file://`. Нужен хостинг или локальный сервер, например `python3 -m http.server` в папке `site`.

## Обновить после правок в проекте

В папке «Qidrix Карьер» выполните:

```bash
npm run build:tour
```

Папка `site/` пересоберётся из тех же исходников, что и основное приложение. Пролёт остаётся и в основном проекте (кнопка «Пролёт»).

## Требования к просмотру

Современный браузер с WebGL 2: Chrome, Edge, Safari или Firefox последних версий, на компьютере или планшете. На слабой графике чёткость картинки снижается автоматически, чтобы сохранить плавность.
